ARENA CLASH — BOTS v0.1

Оригинальный мобильный MOBA-прототип в браузере (не код MLBB).

Что есть:
- 3v3: игрок + 2 союзных бота против 3 вражеских ботов
- виртуальный джойстик
- базовая атака
- 3 умения: рывок, круговой удар, метеор
- миньоны и волны
- по 2 башни и база у каждой команды
- смерть и респавн героев
- золото, опыт и уровни
- победа/поражение при уничтожении базы
- PWA для установки на телефон

КАК ЗАПУСТИТЬ НА ТЕЛЕФОНЕ
1. Загрузите все файлы этой папки в корень GitHub-репозитория.
2. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
3. Откройте выданную HTTPS-ссылку в Safari/Chrome.
4. Игра рассчитана на горизонтальную ориентацию.
5. iPhone: Safari -> Поделиться -> На экран «Домой».

Управление:
- левый джойстик — движение
- ⚔️ — обычная атака ближайшей цели
- ⚡ — рывок
- 🌿 — урон вокруг героя
- ☄️ — сильная атака по ближайшей цели
